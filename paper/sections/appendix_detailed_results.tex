\section{Detailed Results}
\label{app:detailed-results}

This appendix follows the per-dataset comparison style of the CBraMod and
REVE benchmark tables. All local runs inherit the fixed split code of the
applicable CBraMod or REVE benchmark and use the same subject- or trial-level
train, validation, and test partitions as the corresponding reference rows;
the remaining published rows are transcribed from these benchmark tables as
contextual references.

\paragraph{Channel ordering and montage preprocessing.}
All local vision models receive channels in the order produced by the
dataset-specific preprocessing pipeline. We do not reorder channels at runtime
by 10--20 position, Euclidean electrode distance, or any other
physical-coordinate rule, and the folding adapter does not insert or remove
channels. Consequently, the row-block order in Eq.~\ref{eq:fold} is exactly
the stored array order for each dataset. This convention makes the induced
cross-channel neighborhoods reproducible, although their physical
interpretation remains dataset-dependent. The channel lists and preprocessing
choices are included in the released preprocessing configuration.
Binary tasks report BA / PR-AUC / ROC-AUC;
multiclass tasks report BA / Cohen's $\kappa$ / weighted F1. Published values
are transcribed from the CBraMod and REVE tables, whereas local vision rows
are validation-selected results with one final test evaluation per seed.
EfficientNet-B0 uses its ImageNet initialization; ConvNeXt-Tiny and ViT-Small
use DINOv3 pretrained weights.
Supervised EEG models, EEG foundation models, and vision models are separated
into groups; the supervised rows reference EEGNet \citep{lawhern2018eegnet},
EEGConformer \citep{song2023eeg}, SPaRCNet \citep{jing2023development},
ContraWR \citep{yang2021self}, CNN-Transformer \citep{peh2022transformer},
FFCL \citep{li2022motor}, and ST-Transformer \citep{song2021transformer}.
The highest value in each metric column is bold and the
second-highest is underlined. A double dash denotes an unreported
result. All metrics are higher-is-better; local results report the mean and
population standard deviation across five seeds (42--46). The local TUEV
release contains additional training and validation segments, while retaining
the same held-out test set used by the references. Table~\ref{tab:splits} lists
the resulting split sizes and partition rules for all 12 datasets.

\subsection{ISRUC: Sleep Staging}
ISRUC-Sleep provides overnight polysomnography for five-stage sleep classification \citep{khalighi2016isruc}. Each local epoch contains six channels and 6,000 time samples (30 seconds at 200\,Hz). Balanced accuracy, Cohen's $\kappa$, and weighted F1 are computed over epoch labels.
ISRUC uses the published benchmark split (subjects 1--80/81--90/91--100 for
train/validation/test), identical to the \reve{} protocol. The local loader
retains 20 consecutive 30-second epochs per record, but the vision path
reshapes each $[20,C,T]$ sequence into 20 independent samples before folding.
The backbone therefore sees one 30-second epoch at a time and does not
aggregate features or predictions across the 20-epoch context window. Its
outputs are reshaped back to $[20,K]$ so that the loss and reported metrics are
computed against all 20 epoch labels. Thus the 20-epoch storage format does not
give the visual models an additional temporal-context input.
