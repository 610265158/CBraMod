\section{Temporal Folding and Geometry}
\label{app:folding}

\subsection{Temporal-folding definition and geometry}
\label{app:folding-definition}

For an input $X\in\mathbb{R}^{C\times T}$ and a divisor $P$ of $T$, the
phase-interleaved adapter produces $F_P(X)\in\mathbb{R}^{CP\times T/P}$
according to
\[
F_P(X)_{cP+p,w}=X_{c,wP+p},\qquad 0\le p<P.
\]
This is a bijective permutation of the $CT$ samples, so folding changes only
the representation geometry. In contrast, a contiguous reshape assigns each
row a consecutive time chunk; both layouts have identical dimensions but
different local neighborhoods. The adapter pads only the bottom and right
edges to satisfy the backbone stride. For stride $s$, the padded dimensions
and non-padding height occupancy are
\[
H_{\rm pad}=s\left\lceil\frac{CP}{s}\right\rceil,\qquad
W_{\rm pad}=s\left\lceil\frac{T/P}{s}\right\rceil,\qquad
\rho_H=\frac{CP}{H_{\rm pad}}.
\]
Increasing $P$ raises vertical occupancy but reduces horizontal temporal
resolution and increases phase-wrap distance. The geometry rule therefore
selects the smallest valid $P$ reaching the target folded height; the complete
fold-factor sweeps are reported in Appendix~\ref{app:p-ablation}.

\paragraph{Exact invertibility.}
The mapping is bijective: for every original sample index
$t=wP+p$, the inverse is
$X_{c,t}=F_P(X)_{cP+(t\bmod P),\lfloor t/P\rfloor}$. Consequently,
$\|F_P(X)\|_0=\|X\|_0$ and no interpolation, averaging, or frequency-domain
operation is introduced. Any difference between temporal folding and contiguous
reshape therefore comes solely from the neighborhoods presented to the
backbone. The examples below visualize this change of coordinates; they are
not claims that the highlighted patterns are uniquely physiological or
causal.

\subsection{Visual interpretation and examples}
\label{app:folding-visuals}

The visualizations provide three complementary checks. First, the waveform
panels establish the original channel--time coordinates. Second, the folding
panels show that phase $p$ becomes a vertical coordinate while $w$ advances
by $P$ samples horizontally. Third, the real and synthetic examples verify
that localized transients, oscillations, and repeated motifs remain present
after the permutation. Pixel values should therefore be compared through the
index relation above, rather than by interpreting the folded image as a new
measurement.

progression. The upper panels pair three simulated waveforms with their exact

\subsection{What a convolution sees}
\label{app:convolution}
Within one electrode's phase block, a vertical step changes the phase index,
while a horizontal step advances by $P$ original samples. A $k\times k$
convolution therefore mixes offsets
\[
\Delta t=P\Delta w+\Delta p,
\]
where $(\Delta w,\Delta p)$ is a kernel offset in folded coordinates. The
local patch is flattened and multiplied by the kernel weights, followed by
bias and nonlinearity; no special EEG operation is introduced. For $P=4$ and
$k=3$, the direct temporal offsets are
$\{-5,-4,-3,-1,0,1,3,4,5\}$.

At phase-block boundaries a vertical neighborhood can also cross electrodes,
so the interpretation depends on channel ordering. Figure~\ref{fig:channel-crossing}
makes the two regimes explicit. Inside one block, the three columns of a
$3\times3$ window are $P$ samples apart, so the window samples the waveform
like a dilated (atrous) pattern with rate $P$: for $P=4$ its nine taps cover
three consecutive samples around each of $t-P$, $t$, and $t+P$, which is
exactly the offset set above. At a block boundary, however, the $\Delta p=+1$
row is no longer the next phase of the same electrode: row $cP+P-1$ is
adjacent to row $(c+1)P$, so that row reads electrode $c+1$ instead, and its
offsets are measured in the neighbour's own time frame. The crossing therefore
mixes two electrodes only at block boundaries, and the induced neighborhood
depends on channel ordering.

\section{Model-Family Comparison}
\label{app:model-families}

three vision backbones receive the same folded EEG tensor, whereas the EEG

\section{Data and Code Reproducibility Statement}

The codebase records exact dataset paths, input shapes, preprocessing, seeds,
training arguments, logs, and validation-selected checkpoints.  Public data
licenses and access conditions differ by benchmark; no dataset is redistributed
with the paper.  The CHB-MIT manifest follows the subject split of the
\cbramod{} benchmark code (CHB01--20/CHB21--22/CHB23--24 for
train/validation/test) \citep{wang2025cbramod}; the remaining manifests follow
the fixed subject- or trial-level partitions of the \cbramod{} and \reve{}
benchmark code \citep{wang2025cbramod,elouahidi2025reve}, with HMC using the
\reve{} partition \citep{elouahidi2025reve,alvarez2022hmc}.  Reproduction still
requires the documented dataset versions and local split manifests. We use
TUAB v3.0.1 and TUEV v2.0.1; for TUEV, the held-out test partition is the
official evaluation set and contains 29,421 segments in both v2.0.0 and
v2.0.1, while the newer release changes only the training and validation
counts (68,445/15,487 rather than 67,436/15,634).
