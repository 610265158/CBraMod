\section{Method}
\label{sec:method}

\subsection{Overview and problem setting}

For a regular dataset, an EEG segment is
$\mathbf{X}\in\mathbb{R}^{C\times T}$, where $C$ is the number of channels
and $T$ the number of time samples.  A minibatch has shape
$B\times C\times T$.  ISRUC is the sole sequence exception: every record
contains $S=20$ consecutive sleep epochs and has shape
$B\times S\times C\times T$.  We temporarily merge $B$ and $S$ during visual
encoding and restore the sequence dimension before computing the loss.

The objective is deliberately conventional.  Binary tasks use one logit and
binary cross entropy.  Multiclass tasks use cross entropy with label smoothing.
The contribution lies in the interface between $\mathbf{X}$ and a generic 2D
backbone.

\subsection{Lossless temporal folding}

Choose an integer fold factor $P$ such that $P\mid T$ and define
$W=T/P$.  The folding operator $F_P$ maps the waveform to a single-channel
image $\mathbf{I}\in\mathbb{R}^{1\times(CP)\times W}$:

\begin{equation}
\label{eq:fold}
  \mathbf{I}_{1,cP+p,w}
  = \mathbf{X}_{c,wP+p},
  \quad
  0\leq c<C,\ 0\leq p<P,\ 0\leq w<W.
\end{equation}

Rows are ordered by electrode and then by within-group temporal phase.  Thus
all $P$ phase rows from the same electrode remain adjacent.  For example, one
channel with $T=16$ and $P=4$ becomes

\begin{center}
\small
$\begin{bmatrix}
x_0&x_4&x_8&x_{12}\\
x_1&x_5&x_9&x_{13}\\
x_2&x_6&x_{10}&x_{14}\\
x_3&x_7&x_{11}&x_{15}
\end{bmatrix}$.
\end{center}

The resulting raster is a computational view, not a claim that EEG becomes a
physical image. Humans follow amplitude along time; the CNN instead responds
to neighborhoods induced by the raster indices. Folding places short
within-channel temporal segments into contiguous vertical neighborhoods before
strided stages reduce spatial resolution. A side-view/top-view illustration,
a real seizure example, and controlled waveform examples are provided in
Appendix Figs.~\ref{fig:side-top-view}, \ref{fig:seizure-folding}, and
\ref{fig:synthetic-folding-patterns}.

\begin{proposition}[Information preservation]
$F_P$ is a bijection between $\mathbb{R}^{C\times T}$ and
$\mathbb{R}^{(CP)\times(T/P)}$.
\end{proposition}

\begin{proof}
Every original index $(c,t)$ has a unique decomposition
$t=wP+p$, where $p=t\bmod P$ and $w=\lfloor t/P\rfloor$.  Equation
\ref{eq:fold} therefore maps it to exactly one output index.  The inverse is
$\mathbf{X}_{c,wP+p}=\mathbf{I}_{1,cP+p,w}$.  No value is duplicated,
averaged, interpolated, or discarded.
\end{proof}

Folding is consequently not a filter and should not be described as denoising.
It changes only the neighborhoods on which the following network operates.

\subsection{Locality induced by folding}

Consider two folded pixels from the same electrode,
$\mathbf{I}_{cP+p,w}$ and $\mathbf{I}_{cP+p',w'}$.  Their Manhattan distance
in the image is

\begin{equation}
  d_{\mathrm{img}}=|p-p'|+|w-w'|,
\end{equation}

while their temporal separation in the original waveform is

\begin{equation}
  d_{\mathrm{time}}=|(w-w')P+(p-p')|.
\end{equation}

A vertical one-pixel step within an electrode therefore connects consecutive
samples, whereas a horizontal one-pixel step connects samples $P$ time points
apart.  A $k\times k$ convolution combines offsets of the form
$\Delta t=P\Delta w+\Delta p$ within one local receptive field.  For example,
a $3\times3$ kernel at $P=4$ can directly combine offsets
$\{-5,-4,-3,-1,0,1,3,4,5\}$.  This is a polyphase view of the waveform: each
column holds a group of $P$ consecutive samples, and each row follows one
temporal phase across groups.

Figure~\ref{fig:receptive-field-mechanism} summarizes this mechanism and its
interaction with the hierarchical receptive fields of EfficientNet-B0.

\begin{figure*}[t]
\centering
\includegraphics[width=\textwidth]{receptive_field_mechanism.pdf}
\caption{Why phase-folded EEG is compatible with a 2D CNN. Folding is a

The rasterization introduces a phase-wrap boundary.  The original consecutive
pair at phases $P-1$ and $0$ lies across adjacent columns rather than adjacent
rows.  Large $P$ therefore increases height and temporal offset diversity, but
also makes this wrap less local to a small square kernel.

At the boundary between the last phase row of electrode $c$ and the first
phase row of electrode $c+1$, vertical locality becomes cross-electrode and
slightly time-shifted.  This is useful only when the chosen channel order has
meaningful structure.  It also exposes a limitation: the adapter does not know
physical electrode coordinates and cannot distinguish a physiological
neighborhood from an arbitrary row ordering.

\paragraph{Downsampling and signal occupancy.}

EfficientNet-B0 has a nominal total spatial stride of 32.  With no folding,
many datasets provide fewer than 32 channel rows.  The implementation pads
height and width to multiples of 32, so the padded dimensions are

\begin{equation}
  H_{\mathrm{pad}}=32\left\lceil\frac{CP}{32}\right\rceil,
  \qquad
  W_{\mathrm{pad}}=32\left\lceil\frac{T/P}{32}\right\rceil.
\end{equation}

The fraction of non-padding rows is

\begin{equation}
  \rho_H(P)=\frac{CP}{H_{\mathrm{pad}}}.
\end{equation}

For a 16-channel recording, $P=1$ occupies only half of a 32-row padded input,
whereas $P=2$ occupies every row.  More generally, increasing $P$ delays the
collapse of signal-bearing height positions through the convolutional stages.
This does not guarantee improvement: an excessively large $P$ coarsens the
horizontal time step, increases phase-wrap distance, and creates more
artificial vertical boundaries.

\subsection{Architecture-aligned fold-factor selection}
\label{sec:p-selection}

To avoid choosing $P$ independently by test-set performance, we define a
deterministic geometry rule from the input shape and the backbone stride.  For
each divisor $P$ of $T$, let

\begin{equation}
  H(P)=CP, \qquad W(P)=T/P.
\end{equation}

EfficientNet-B0 has total spatial stride 32. To retain at least two
signal-bearing cells along height before global pooling, we target at least 64
folded rows and choose the smallest valid factor. A native channel count very
close to 64 is treated as sufficient; specifically, SEED-V's 62 channels are
left unfolded. We select

\begin{equation}
\label{eq:p-geometry-rule}
 P_{\mathrm{geo}}=
 \begin{cases}
  1, & C\geq62,\\
  \min\{P\in\mathbb{N}: P\mid T,\ CP\geq64\}, & C<62.
 \end{cases}
\end{equation}

The target height 64 leaves two signal-bearing cells after a nominal stride of
32 instead of merely avoiding collapse. This is an architecture-alignment
heuristic, not a claim that 64 rows are intrinsically optimal for EEG. It uses
only $(C,T)$ and the backbone geometry, and therefore can be fixed before
training or test evaluation.

The rule also makes the trade-off explicit. Increasing $P$ raises vertical
occupancy but shortens the horizontal sequence and makes one horizontal pixel
span $P$ original samples. Selecting the smallest factor that reaches the
height target limits
this loss of horizontal resolution and the number of phase-wrap boundaries.

\begin{hypothesis}[Geometry alignment]
Temporal folding helps when it improves signal occupancy and exposes useful
within-electrode phase and $P$-spaced relations before hierarchical
downsampling.  Gains
should not be universal, and should weaken when physical electrode topology or
long uninterrupted horizontal context is more important.
\end{hypothesis}

\subsection{Vision backbone and task head}

The main model is intentionally small:

\begin{center}
\fbox{%
\begin{minipage}{0.91\linewidth}
\centering
$[B,C,T]$
$\xrightarrow{\;F_P\;}$
$[B,1,CP,T/P]$
$\xrightarrow{\;\text{zero pad}\;}$
$\xrightarrow{\;\text{ImageNet EfficientNet-B0}\;}$
$\xrightarrow{\;\text{global average pool}\;}$
$\xrightarrow{\;\text{linear}\;}$ logits.
\end{minipage}}
\end{center}

We instantiate the timm EfficientNet-B0 with one input channel and ImageNet
weights \citep{wightman2019timm}.  The natural-image classifier is not used;
the feature encoder contains approximately 4.0M parameters.  A dropout layer
and task-specific linear classifier are trained together with the backbone.
The model contains no EEG-specific self-supervised weights, Fourier features,
self-attention mechanism, or learned positional embedding.
