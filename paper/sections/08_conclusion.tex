\section{Conclusion}

We introduced phase-interleaved, lossless temporal folding as an interface
between raw EEG and generic vision backbones. It changes no waveform values
and adds no learned parameters, yet it substantially changes the neighborhoods
and downsampling trajectory seen by a 2D CNN. Across 12 benchmarks,
EfficientNet-B0 is competitive with the displayed supervised and
EEG-foundation baselines on several tasks; ConvNeXt-Tiny leads the FACED
results, while the strongest EEG reference remains ahead on TUAB, SEED-V, and
Mumtaz2016. The uniform metric reporting keeps these trade-offs visible
without collapsing unlike metrics into one score, and the pattern supports
competitiveness rather than universal superiority.

The broader message is methodological: representation geometry should be a
first-class baseline variable before downstream accuracy is attributed to
large-scale EEG pretraining. Matched five-seed initialization controls show
that ImageNet/DINOv3 weights improve eight of nine backbone--dataset
comparisons over random initialization, direct evidence that visual
pretraining transfers to EEG after geometry alignment. Vision pretraining is
therefore not a universal free lunch, but a strong reusable prior whose
benefit appears when EEG geometry matches the inductive bias of the encoder.
