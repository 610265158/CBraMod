\section{Detailed Results}
\label{app:detailed-results}

This appendix follows the per-dataset comparison style of the CBraMod and
REVE benchmark tables. The split manifests used by the local runs are
generated by the same repository split code and reproduce the corresponding
subject- or trial-level partitions. Binary tasks report BA / PR-AUC / ROC-AUC;
multiclass tasks report BA / Cohen's $\kappa$ / weighted F1. Published values
are transcribed from the CBraMod and REVE tables, whereas local vision rows
are validation-selected YAML results with one final test evaluation per seed.
EfficientNet-B0 uses its ImageNet initialization; ConvNeXt-Tiny and ViT-Small
use DINOv3 pretrained weights.
Supervised EEG models, EEG foundation models, and vision models are separated
into groups. The highest value in each metric column is bold and the
second-highest is underlined. A double dash denotes an unreported or pending
result. TUEV version and REVE--ISRUC preprocessing differences are retained in
the dataset notes below.
