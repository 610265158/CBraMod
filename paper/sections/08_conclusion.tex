\section{Conclusion}

We introduced phase-interleaved, lossless temporal folding as a parameter-free
interface between EEG and generic vision backbones. Across 12 heterogeneous
benchmarks, a ConvNeXt-Tiny model trained without EEG-specific pretraining
exceeds the strongest included published EEG foundation reference on both main
metrics in 8 tasks. This result spans clinical, sleep, affective, motor-
imagery, and cognitive EEG settings, although EEG-specific models remain
stronger on several tasks.

Our results show that publicly available visual representations, when paired
with a suitable interface for EEG, can provide a strong and reproducible
starting point for EEG decoding. This offers the community a practical
alternative to building a new EEG-specific pretraining pipeline for every
setting, while providing a necessary baseline for measuring the incremental
value of EEG-specific pretraining.
