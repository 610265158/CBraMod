ISRUC uses batch size 16, three warmup epochs, EMA decay .995, time roll
($p=.5$, maximum fraction .25), and mirror augmentation ($p=.5$), which swaps
left/right channel pairs according to the known montage.  PhysioNet-MI uses
batch size 32, three warmup epochs, EMA decay .995, float16 AMP, and no data
augmentation; left/right mirror is disabled because its motor-imagery labels
are side-specific.  MentalArithmetic
uses batch size 64, three warmup epochs,
\texttt{pos\_weight=3}, time roll ($p=.5$, maximum fraction .25), and mirror
($p=.5$).
No finalized run uses random amplitude scaling.  SHU-MI uses its documented
input-scale exception; all other datasets use the default clip-to-1024 and
divide-by-32 preprocessing.

\section{Formal Evaluation Protocol}
\label{app:protocol}

The executable protocol is:

\begin{enumerate}
    \item Verify every configured dataset path with
    \texttt{experiments/run\_downstream.sh --check\_only --all}.
    \item Smoke-test the current code using a CPU, random-initialized one-batch
    forward pass.
    \item During recipe search, set \texttt{test\_each\_epoch=false} and
    \texttt{run\_final\_test=false}.  Rank candidates by mean best validation
    metric across two search seeds.
    \item Freeze the winning recipe before the formal runs.
    \item Train seeds 3407, 3408, and 3409 with
    \texttt{test\_each\_epoch=false}.  Save the best validation checkpoint.
    \item Restore that checkpoint and evaluate the test set exactly once.
    \item Aggregate the three final test values as mean and population standard
    deviation.  Do not choose a seed or epoch using test performance.
\end{enumerate}

All downstream training is launched through
\texttt{bash experiments/run\_downstream.sh}; direct invocation of the legacy
entrypoint can silently change path resolution.

\section{Submission-Critical Experiments}
\label{app:critical}

The following items are required before treating this draft as an ICLR-ready
empirical paper:

\begin{enumerate}
    \item reproduce \cbramod{} under identical splits, preprocessing, seeds,
    and validation-only selection;
    \item run random-initialized EfficientNet-B0 and frozen ImageNet linear
    probes on all datasets;
    \item compare $P=1,2,4,8$ under a fixed optimization budget on a
    representative subset;
    \item add EEGNet and DeepConvNet with matched validation tuning;
    \item report parameters, FLOPs, peak memory, examples/second, and wall time;
    \item evaluate channel permutation, channel dropout, and missing-electrode
    robustness;
    \item use subject-level bootstrap confidence intervals or paired tests;
    \item freeze a prospective protocol that has not been chosen using the
    current test sets.
\end{enumerate}

\section{Data and Code Reproducibility Statement}

The codebase records exact dataset paths, input shapes, preprocessing, seeds,
training arguments, logs, and validation-selected checkpoints.  Public data
licenses and access conditions differ by benchmark; no dataset is redistributed
with the paper.  Final release artifacts should include preprocessing hashes,
split manifests, environment versions, and commands for every table row.  TUAB
and TUEV version numbers must be included because sample counts differ across
releases and historical pipelines.
