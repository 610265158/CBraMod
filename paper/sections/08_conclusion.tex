\section{Conclusion}

We introduced a phase-interleaved, lossless temporal-folding interface between
raw EEG and generic vision backbones.  The method changes no waveform values
and adds no learned adapter parameters, yet it substantially changes the
neighborhoods and downsampling trajectory seen by a 2D CNN.  Across 11
benchmarks, EfficientNet-B0 exceeds published \cbramod{} primary metrics on
six datasets, is within 0.1 percentage points on one, and trails on four.  The
pattern supports competitiveness, not universal superiority, and still
requires same-pipeline foundation-model reproduction for a paired claim.

The broader message is methodological: before attributing downstream accuracy
to large-scale EEG pretraining, representation geometry must be treated as a
first-class baseline variable.  Completing the same-split foundation-model
reproductions, prospective evaluation, initialization controls, and
topology-aware extension will determine whether this observation matures into
a general EEG learning principle.  In this sense, vision pretraining is not a
universal free lunch, but a strong reusable prior whose benefit becomes visible
when EEG geometry is matched to the inductive bias of the encoder.
