\section{Detailed Results}
\label{app:detailed-results}

Following the per-dataset presentation of \reve{} Appendix C
\citep{elouahidi2025reve}, this section reports both metrics for every dataset.
Published supervised and foundation-model values are transcribed from the
shared benchmark tables in \cbramod{} and \reve{}
\citep{wang2024cbramod,elouahidi2025reve}. The supervised suite contains
EEGNet, EEGConformer, SPaRCNet, ContraWR, CNN-Transformer, FFCL, and
ST-Transformer. All use the subject- or trial-level partitions reported by
\cbramod{} and, where available, \reve{}, except for the documented TUEV
version difference \citep{wang2024cbramod,elouahidi2025reve}. Binary tasks
report PR-AUC/AUROC; multiclass tasks report Cohen's $\kappa$/weighted F1.
Balanced accuracy is omitted from the formal tables because it was not part of
our frozen reporting protocol.
Published and local rows still differ in preprocessing, optimization, seeds,
and checkpoint selection, so these are direct benchmark comparisons rather
than paired reproductions. Bold denotes the best displayed mean per metric.
