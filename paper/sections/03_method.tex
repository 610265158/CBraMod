\section{Method}
\label{sec:method}

\subsection{Overview and problem setting}

Each EEG segment is represented as a channel--time tensor
$\mathbf{X}\in\mathbb{R}^{C\times T}$, where $C$ is the number of channels
and $T$ is the number of time samples. A minibatch is passed through the same
folding adapter and visual encoder before task-specific prediction. Dataset-specific
sequence handling is described in Appendix~\ref{app:protocol}.

The objective is deliberately conventional.  Binary tasks use one logit and
binary cross entropy.  Multiclass tasks use cross entropy with label smoothing.
The contribution lies in the interface between $\mathbf{X}$ and a generic 2D
backbone.

\subsection{Lossless temporal folding}

Choose an integer fold factor $P$ such that $P\mid T$ and define
$W=T/P$.  The folding operator $F_P$ maps the waveform to a single-channel
image $\mathbf{I}\in\mathbb{R}^{1\times(CP)\times W}$:

\begin{equation}
\label{eq:fold}
  \mathbf{I}_{1,cP+p,w}
  = \mathbf{X}_{c,wP+p},
  \quad
  0\leq c<C,\ 0\leq p<P,\ 0\leq w<W.
\end{equation}

Rows are ordered by electrode and then by within-group temporal phase.  Thus
all $P$ phase rows from the same electrode remain adjacent.  For example, one
channel with $T=16$ and $P=4$ becomes

\begin{center}
\small
$\begin{bmatrix}
x_0&x_4&x_8&x_{12}\\
x_1&x_5&x_9&x_{13}\\
x_2&x_6&x_{10}&x_{14}\\
x_3&x_7&x_{11}&x_{15}
\end{bmatrix}$.
\end{center}

Figure~\ref{fig:folding-overview} illustrates the reindexing on a controlled
example and on a real 16-channel TUEV segment. The raster is a computational
representation, not a physical image of the scalp. It gives the visual encoder
a taller signal-bearing input and places short within-channel temporal
patterns in local 2D neighborhoods before strided stages reduce resolution.
Additional geometric, seizure, and controlled-waveform visualizations appear
in Appendix Figs.~\ref{fig:side-top-view}, \ref{fig:seizure-folding}, and
\ref{fig:synthetic-folding-patterns}.

\begin{proposition}[Information preservation]
$F_P$ is a bijection between $\mathbb{R}^{C\times T}$ and
$\mathbb{R}^{(CP)\times(T/P)}$.
\end{proposition}

\begin{proof}
Every original index $(c,t)$ has a unique decomposition
$t=wP+p$, where $p=t\bmod P$ and $w=\lfloor t/P\rfloor$.  Equation
\ref{eq:fold} therefore maps it to exactly one output index.  The inverse is
$\mathbf{X}_{c,wP+p}=\mathbf{I}_{1,cP+p,w}$.  No value is duplicated,
averaged, interpolated, or discarded.
\end{proof}

Folding is consequently not a filter and should not be described as denoising.
It changes only the neighborhoods on which the following network operates.
Its purpose is twofold: to preserve signal-bearing height for sparse montages,
and to expose existing temporal patterns in a structured phase--time layout.
The model can still access every waveform value, while local 2D kernels now
combine adjacent phases and $P$-spaced context. Information preservation alone
does not guarantee an advantage; the benefit depends on whether this new
computational neighborhood matches the task.

\subsection{Locality induced by folding}

Consider two folded pixels from the same electrode,
$\mathbf{I}_{cP+p,w}$ and $\mathbf{I}_{cP+p',w'}$.  Their Manhattan distance
in the image is

\begin{equation}
  d_{\mathrm{img}}=|p-p'|+|w-w'|,
\end{equation}

while their temporal separation in the original waveform is

\begin{equation}
  d_{\mathrm{time}}=|(w-w')P+(p-p')|.
\end{equation}

A vertical one-pixel step within an electrode therefore connects consecutive
samples, whereas a horizontal one-pixel step connects samples $P$ time points
apart.  A $k\times k$ convolution combines offsets of the form
$\Delta t=P\Delta w+\Delta p$ within one local receptive field.  The local
patch is flattened and multiplied by the kernel weights, so this is an
ordinary dot product followed by bias and nonlinearity.  For $P=4$, a
$3\times3$ kernel directly mixes offsets
$\{-5,-4,-3,-1,0,1,3,4,5\}$.  This is a polyphase view of the waveform: each
column holds a group of $P$ consecutive samples, and each row follows one
temporal phase across groups.

Figure~\ref{fig:folding-overview} summarizes this mechanism and its
interaction with the hierarchical receptive fields of EfficientNet-B0.

\caption{Lossless phase-interleaved temporal folding and its interaction with

The rasterization introduces a phase-wrap boundary.  The original consecutive
pair at phases $P-1$ and $0$ lies across adjacent columns rather than adjacent
rows.  Large $P$ therefore increases height and temporal offset diversity, but
also makes this wrap less local to a small square kernel.

At the boundary between the last phase row of electrode $c$ and the first
phase row of electrode $c+1$, vertical locality becomes cross-electrode and
slightly time-shifted.  This is useful only when the chosen channel order has
meaningful structure.  It also exposes a limitation: the adapter does not know
physical electrode coordinates and cannot distinguish a physiological
neighborhood from an arbitrary row ordering.

\paragraph{Downsampling and signal occupancy.}

EfficientNet-B0 has a nominal total spatial stride of 32.  With no folding,
many datasets provide fewer than 32 channel rows.  The implementation pads
height and width to multiples of 32, so the padded dimensions are

\begin{equation}
  H_{\mathrm{pad}}=32\left\lceil\frac{CP}{32}\right\rceil,
  \qquad
  W_{\mathrm{pad}}=32\left\lceil\frac{T/P}{32}\right\rceil.
\end{equation}

The fraction of non-padding rows is

\begin{equation}
  \rho_H(P)=\frac{CP}{H_{\mathrm{pad}}}.
\end{equation}

For a 16-channel recording, $P=1$ occupies only half of a 32-row padded input,
whereas $P=4$ produces 64 signal-bearing rows. A four-channel PSG recording
such as HMC requires $P=16$, whereas a 64-channel recording already satisfies
the occupancy target and remains at $P=1$. Dense montages may also preserve
finer spatial information, but the present benchmark cannot separate channel
count from montage and task effects. More generally, increasing $P$ delays the
collapse of signal-bearing height positions through the convolutional stages.
This does not guarantee improvement: an excessively large $P$ coarsens the
horizontal time step, increases phase-wrap distance, and creates more
artificial vertical boundaries.

\subsection{Architecture-aligned fold-factor selection}
\label{sec:p-selection}

To provide a reproducible starting point, we define a geometry-based default
from the input shape and the backbone stride rather than selecting an arbitrary
value for each dataset.  For
each divisor $P$ of $T$, let

\begin{equation}
  H(P)=CP, \qquad W(P)=T/P.
\end{equation}

EfficientNet-B0 has total spatial stride 32. To retain at least two
signal-bearing cells along height before feature aggregation, we target at least
64 folded rows and choose the smallest valid factor. A native channel count very
close to 64 is treated as sufficient; specifically, SEED-V's 62 channels are
left unfolded. We select

\begin{equation}
\label{eq:p-geometry-rule}
 P_{\mathrm{geo}}=
 \begin{cases}
  1, & C\geq62,\\
  \min\{P\in\mathbb{N}: P\mid T,\ CP\geq64\}, & C<62.
 \end{cases}
\end{equation}

The target height 64 leaves two signal-bearing cells after a nominal stride of
32 instead of merely avoiding collapse. This is an architecture-alignment
heuristic, not a claim that 64 rows are intrinsically optimal for EEG. It uses
only $(C,T)$ and the backbone geometry, and therefore can be fixed before
training or test evaluation.

The rule also makes the trade-off explicit. Increasing $P$ raises vertical
occupancy but shortens the horizontal sequence and makes one horizontal pixel
span $P$ original samples. Selecting the smallest factor that reaches the
height target limits
this loss of horizontal resolution and the number of phase-wrap boundaries.
The geometry rule is a structural prior, not a claim that one value of $P$ is
optimal for every task or backbone. EEG datasets differ in channel topology,
sampling rate, temporal support, and signal quality: discriminative patterns
may be short and local or may depend on long temporal context. When additional
compute is available, a task-specific sweep over admissible factors can
therefore be selected on the validation split; the test set is accessed once
after the factor and checkpoint have been fixed.

\begin{hypothesis}[Geometry alignment]
Temporal folding helps when it improves signal occupancy and exposes useful
within-electrode phase and $P$-spaced relations before hierarchical
downsampling.  Gains
should not be universal, and should weaken when physical electrode topology or
long uninterrupted horizontal context is more important.
\end{hypothesis}

\subsection{Vision backbone and task head}

All three visual backbones share the folding interface and use a
dataset-specific feature aggregation followed by a linear classifier:

\begin{center}
\fbox{%
\begin{minipage}{0.91\linewidth}
\centering
\(\begin{gathered}
[B,C,T]
\xrightarrow{\;F_P\;}
[B,1,CP,T/P]
\xrightarrow{\;\text{zero pad}\;}
\text{Vision backbone}
\longrightarrow \mathbf{Z}
\\[6pt]
\mathbf{Z}
\xrightarrow{\;\text{GAP / CLS token / Flatten}\;}
\mathbf{z}
\xrightarrow{\;\text{dropout + linear}\;}
\text{logits}
\end{gathered}\)
\end{minipage}}
\end{center}

We use timm backbones with one input channel \citep{wightman2019timm}:
EfficientNet-B0 initialized from ImageNet, and ConvNeXt-Tiny and ViT-Small
initialized from DINOv3 LVD-1689M visual weights. The natural-image classifier
is bypassed; the encoder and a new task-specific head are fine-tuned jointly,
without EEG self-supervised pretraining. EfficientNet-B0 has approximately
4.01M encoder parameters, excluding the task head.

For CNN feature maps, \textbf{global average pooling (GAP)} averages over
the final spatial positions. For ViT, \textbf{CLS-token aggregation} uses the
final classification-token representation. \textbf{Flatten aggregation}
instead vectorizes the complete CNN feature map or ViT token tensor before
the dropout and linear layer, retaining separate features for each position.
The ViT tensor includes the prefix tokens returned by the encoder.

When EEG signals are weak, discriminative responses may be confined to a
small subset of feature locations. GAP can dilute these responses by averaging
them with background activations, making learning difficult. Flatten allows
the classifier to learn separate weights for each position and feature,
providing an alternative when global aggregation is insufficient. This adds
head parameters and requires a fixed feature shape within each dataset.

We use a two-stage readout policy during recipe selection. We first try the
compact aggregation appropriate to the backbone—GAP for CNNs and the CLS token
for ViT. If this representation does not converge stably or underfits on the
validation split, we fall back to a flatten--FC head, following the practical
principle of retaining the complete encoder representation for a learned
task readout used in prior EEG foundation-model pipelines
\citep{wang2024cbramod,elouahidi2025reve}. The fallback changes only the
readout capacity; it does not alter the folding interface or the input values.
The aggregation choice is made from validation behavior and recorded in the
corresponding YAML configuration, without consulting the test set.

The reported EfficientNet-B0 recipes use GAP except for FACED, which uses
flatten. ConvNeXt-Tiny uses GAP on TUEV and ISRUC and flatten on the other
completed tasks in the 12-dataset suite; the reported ViT-Small recipes use
flatten, with CLS-token variants recorded as separate comparisons. All head
choices follow the corresponding YAML recipes.
